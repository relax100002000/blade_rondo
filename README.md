# Blade Rondo P2P · 純前端線上對戰

雙方瀏覽器透過 **MQTT over WebSocket** 連到公開的 EMQX broker
（`wss://broker.emqx.io:8084/mqtt`）互傳訊息，**不需要自己跑伺服器**。

卡牌資料來自 https://sdrice.name/br.html  
（旭翼文化 / Domina Game 版權所有，本程式僅供學習研究用途）

## 三種玩法（任選）

### A. 本地雙擊執行（最快）
直接雙擊 `index.html`，兩台電腦／兩個分頁各別開啟即可。

### B. 部署到 GitHub Pages（推薦，朋友只要點連結即可玩）
1. 在 GitHub 建一個 public repo（例如 `blade-rondo`）。
2. 把資料夾裡這 7 個檔案放到 repo 根目錄並 push：
   `index.html` / `style.css` / `cards.js` / `game.js` / `net.js` / `client.js` / `README.md`
3. Repo → **Settings** → 左邊 **Pages** → Source 選 `Deploy from a branch` →
   Branch 選 `main` / `/ (root)` → **Save**。
4. 等 1–2 分鐘，GitHub 會給你網址：`https://<你的帳號>.github.io/blade-rondo/`
5. 把網址傳給對手 → 雙方都打開 → 一個按「建立房間」、一個用房號加入 → 開戰。

> 因為 GitHub Pages 預設提供 HTTPS，而 EMQX broker 也是 `wss://` 加密連線，
> 所以可以順利在瀏覽器中啟用 WebSocket。

### C. 其他免費靜態主機
- **Cloudflare Pages**：連 GitHub repo 自動部署，CDN 速度最快
- **Netlify Drop**：把資料夾直接拖到網頁就部署（連 git 都不用）
- **Vercel**：連 GitHub repo 即可

## 邀請連結

建房後分享面板會自動產生 `https://你的網址/?room=AZCK` 形式的邀請連結，
按「**複製連結**」傳給對手；對手點開時房號會自動填好，只要輸入名稱按「加入」即可。

URL 也會被改寫成含房號的版本，所以你 refresh 也不會掉房號（但 host 角色需要重新點建房）。

## 架構

```
[A 端瀏覽器]                                 [B 端瀏覽器]
   index.html                                   index.html
   ├ cards.js                                   ├ cards.js
   ├ game.js   <-- 主機端跑遊戲邏輯              ├ game.js
   ├ net.js    -- MQTT WebSocket --             ├ net.js
   └ client.js          │                       └ client.js
                        ▼
              wss://broker.emqx.io:8084/mqtt
                topic = bladerondo/v2/{房號}
```

- **host**（點「建立房間」者）：執行 `game.js` 全部狀態機，收到對方 action 後處理 → 廣播 state
- **guest**（點「加入」者）：只送 action、收 state、渲染

## 訊息協定

兩邊在同一 MQTT topic 上發 JSON：

| 來自 | type | 說明 |
|------|------|------|
| guest | `guest_hello` | 加入時送 `{name}`，host 收到後新增玩家並廣播 state |
| host  | `host_announce` | 連線完成時廣播，讓 guest 知道 host 在 |
| host  | `state` | 廣播給 guest 的 publicView |
| guest | `action` | `{kind, ...}`，kind: `submit_deck` / `play_card` / `react` / `pass_react` / `end_turn` / `rematch` |
| 任一  | `chat` | `{text, fromName}` |

訊息都帶 `from: myId` 欄位，自己發的訊息會被自己過濾掉避免迴圈。

## 想換掉 broker？

EMQX 公開 broker 雖然免費但無 SLA。要改用其他 broker 只要修改 `net.js` 的 `BROKERS` 陣列：

```js
const BROKERS = [
  'wss://broker.hivemq.com:8884/mqtt',
  'wss://test.mosquitto.org:8081',
];
```

要更穩定建議自己註冊 HiveMQ Cloud 免費方案（取得專屬 WSS URL 與帳密），
在 `net.js` 的 `mqtt.connect()` options 加上 `username` / `password`。

## Wave 2 凍結機制修正（v8）

讀完 Frost Veil 官方規則書後發現我 v7 對「凍結」的詮釋**完全錯誤**：

**v7 錯誤**：凍結卡打出時立即發動效果 + 留場
**v8 正確**：

1. 從手牌打出凍結卡 → **只進設置區**，主效果不發動
2. 之後輪到自己時，可**免費啟動**該凍結卡（點擊藍色 ❄ chip）
3. 啟動後依規則：L 卡進棄牌，非 L 卡歸手

### 已修正的凍結卡

- **凍刃劍** (No.61)：打出只凍結，啟動才物理攻擊
- **冰錐之雪鈴花** (No.66)：打出只凍結，啟動才魔法攻擊（1）
- **結果之柔和音** (No.71)：打出只凍結，啟動才選擇 攻+1 / 魔力+1
- **調停之《鐘》** (No.73)：打出只凍結，啟動才令生命變 8

### UI 改動

戰場上你的凍結卡顯示為藍色「❄ XXX (免費啟動)」chip，點擊即啟動。對手只看得到凍結張數 `❄×N`。
